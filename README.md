# OpenGravity

Prototipo de agente de Telegram en TypeScript. El repositorio contiene manifiestos de dependencias, configuración Docker/Vercel y un ZIP histórico. El punto de entrada `src/index.ts` no está presente como archivo directamente versionado en la rama actual; no se garantiza que compile o se despliegue.

Antes de ejecutar: revisar y recuperar el código original del ZIP, comprobar secretos y licencias, configurar variables de entorno localmente, validar dependencias y probar el arranque. No subir credenciales de Telegram, OpenAI, Groq, Firebase ni ElevenLabs.
